# Changelog

All notable changes to this project are documented in this file. New entries
are generated by [knope](https://knope.tech) from changesets — see
`DEVELOPMENT.md` for the release workflow.

## 2.0.0 (2026-10-27)

### Breaking Changes

#### Upgrade to Wails v3

The app is now built on Wails v3. On Linux it requires GTK4 and WebKitGTK 6.0
(Ubuntu 24.04+, Debian 13+, Fedora, Arch); the separate webkit2gtk 4.0 and 4.1
downloads are replaced by a single `gtfs-planner_<version>_linux_<arch>.tar.gz`
per architecture, and distributions that only ship webkit2gtk 4.0 (e.g. Ubuntu
22.04) are no longer supported.

### Features

- Show the app version in Settings

## 1.1.0 (2026-09-21)

### Features

- Added frontend tests
- Export files as `.gtfs-journey` instead of `.journey` and associate this file-type with the app on windows and macOS so we can open the files by double clicking

#### Proper error message, when GTFS database is outdated

When starting with an outdated GTFS database it displayed that the file is valid for `-77 days`. Fixed with a proper message
that the database is expired and offer to download a fresh one

#### Updated dependencies to the most current versions

- Updated TypeScript to version 7.
- This is currently incompatible with ESlint, so switched to OXlint.
- Updated maplibre-gl to version 6
- Updated massively outdated vite to version 8.3

### Fixes

- Do not reset selected transport types when adding a new station to the trip
- Fixed that the transport types selection was reset to "all" after a new stop has been added to the trip

## 1.0.0

- Initial release.
